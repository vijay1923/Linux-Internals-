# Linux Internals – Learning Repository

This repository contains my learning work and practice code related to **Linux Internals** and **system-level programming in C**.

The goal of this repo is to understand how Linux works internally by implementing and experimenting with core OS concepts such as processes, memory management, IPC, threads, and signals.

---

## 📁 Repository Structure

- **file_management/**
  - File handling, system calls, and filesystem-related concepts

- **function_pointer/**
  - Function pointer usage and examples in C

- **ipc/**
  - Inter-Process Communication (pipes, message queues, shared memory, etc.)

- **library/**
  - Static and dynamic libraries

- **libri_fun/**
  - Practice programs related to library functions

- **ml/**
  - Experimental or learning-related code (machine learning or misc practice)

- **process/**
  - Process creation, forking, exec, and process lifecycle

- **projects/memory_management/**
  - Memory management concepts and mini-projects

- **resource_management/**
  - Resource handling and optimization techniques

- **signal/**
  - Signal handling and signal-based communication

- **threads/**
  - Multithreading using pthreads and synchronization mechanisms
